CERTIFICATE

自动续签，凭据独立

尚未配置证书。

在服务器运行以下命令，按提示输入指定 Zone 的 API Token。凭据不会经过网页。

sudo panelctl cert panel.example.com

用于节点 TLS。面板也使用 HTTPS 时，在命令末尾加 --panel-https。DNS 验证无需开放 80 端口。

RECOVERY

备份与恢复

备份含节点密钥与流量，不含管理员密码、Cloudflare Token 或证书私钥。

请妥善保管备份文件。仅支持本面板 JSON 格式；旧 x-ui 需手动迁移。

CORE

独立的 Xray 服务

—

核心更新与二进制回滚通过服务器执行：

sudo panelctl core update
sudo panelctl core rollback

下载校验 SHA-256，先测试现有配置；更新或重启会短暂中断节点连接。
